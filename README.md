# AI Control Room Extension

Публичный репозиторий пользовательского дистрибутива AI Control Room.

Актуальный релиз: [AI Control Room 0.4.1](https://github.com/Satori28/ai-control-room-extension/releases/tag/v0.4.1).

Скачать расширение: [ai-control-room-0.4.1.zip](https://github.com/Satori28/ai-control-room-extension/releases/download/v0.4.1/ai-control-room-0.4.1.zip).

Для установки нужен Google Chrome или Chromium и доступ к production-сервису:

https://control.neuro-ceh.ru

Полная инструкция находится в описании релиза и внутри ZIP в файле `INSTALL.md`.

Скачивание расширения само по себе не создаёт аккаунт и не выдаёт доступ к сервису.
